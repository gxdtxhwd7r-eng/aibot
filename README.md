# АМК AI — Комиссионная продажа

Локальный MVP для менеджера автосалона: вставляет текст объявления, анализирует его через OpenAI и создаёт персональное первое сообщение продавцу. Приложение не сохраняет объявления и не отправляет сообщения автоматически.

## Что уже работает

- Определение автомобиля, подходящего «крючка» и генерация живого обращения от Никиты, компания АМК.
- Структурированный ответ API (`ok` или `do_not_contact`).
- Предварительная локальная проверка прямых юридических обременений и запретов на обращения автосалонов — до отправки текста в OpenAI.
- Особая обработка фразы «перекупов не беспокоить»: она сама по себе не блокирует предложение честной комиссионной продажи.
- Понятные ошибки при пустом поле, отсутствующем ключе и недоступном API.
- Копирование результата, повторная генерация и очистка формы.
- Отдельная база сценариев возражений для будущего этапа.

## Быстрый запуск на Windows

### 1. Установите Python

Установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/windows/). В установщике обязательно отметьте **Add Python to PATH**.

### 2. Установите проект

1. Скачайте или распакуйте папку проекта.
2. Дважды щёлкните `install.bat`.
3. Дождитесь сообщения об успешной установке.

Скрипт создаст изолированное окружение `.venv`, установит зависимости и скопирует `.env.example` в `.env` (если файла ещё нет).

### 3. Добавьте API-ключ

Откройте файл `.env` обычным Блокнотом и вставьте ключ после знака `=`:

```env
OPENAI_API_KEY=sk-ваш_ключ
OPENAI_MODEL=gpt-5.4-mini
```

Не добавляйте кавычки и не публикуйте файл `.env`. Он уже исключён из Git. Ключ используется только backend-сервером и никогда не попадает во frontend.

### 4. Запустите приложение

Дважды щёлкните `run.bat`. Откроется браузер по адресу:

```text
http://127.0.0.1:8000
```

Не закрывайте окно командной строки, пока пользуетесь приложением. Для остановки нажмите `Ctrl+C` или закройте окно.

## Установка командами (Windows PowerShell)

Если удобнее выполнять команды вручную:

```powershell
cd C:\путь\к\aibot
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Если PowerShell запрещает активацию скрипта, она не обязательна — используйте исполняемый файл окружения напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

## Запуск backend и frontend

Frontend — статическая страница, которую раздаёт backend. Поэтому для обычной работы нужен только **один** процесс:

```powershell
python -m uvicorn backend.main:app --reload
```

- Приложение: <http://127.0.0.1:8000>
- Проверка сервера: <http://127.0.0.1:8000/api/health>
- Интерактивная документация API: <http://127.0.0.1:8000/api/docs>

Отдельный Node.js-сервер и сборка frontend не нужны.

## Настройки `.env`

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `OPENAI_API_KEY` | пусто | Секретный ключ OpenAI (обязателен для генерации) |
| `OPENAI_MODEL` | `gpt-5.4-mini` | Модель генерации |
| `OPENAI_TIMEOUT_SECONDS` | `45` | Тайм-аут запроса к OpenAI |
| `APP_HOST` | `127.0.0.1` | Адрес для ручного запуска |
| `APP_PORT` | `8000` | Порт для ручного запуска |

После изменения `.env` перезапустите сервер. Значения `APP_HOST` и `APP_PORT` документируют настройки; для изменения адреса при ручном запуске передайте их параметрами `uvicorn`.

## API

`POST /api/generate`

Запрос:

```json
{
  "advertisement": "Lada Vesta, 2021 год, один владелец, обслуживание у дилера"
}
```

Успешный результат:

```json
{
  "status": "ok",
  "car": "Lada Vesta",
  "hook": "Один владелец и подтверждённое дилерское обслуживание",
  "message": "Здравствуйте! Никита, компания АМК...",
  "reason": null
}
```

При прямом запрете или обременении:

```json
{
  "status": "do_not_contact",
  "car": null,
  "hook": null,
  "message": null,
  "reason": "НЕ ПИСАТЬ — обнаружено юридическое обременение."
}
```

## Проверка проекта

Для разработки установите тестовые зависимости и запустите тесты:

```powershell
pip install -r requirements-dev.txt
pytest -q
```

Локальный тест health endpoint без расхода средств:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/health
```

Тест генерации требует действующего `OPENAI_API_KEY` и расходует небольшой объём API-квоты.

## Приватность и ограничения MVP

- Тексты объявлений не записываются в файлы или базу данных, но для анализа отправляются в OpenAI API.
- API-ключ хранится только локально в `.env` и читается backend-сервером.
- В MVP **нет** интеграций с Авито, Дромом или Auto.ru.
- В MVP **нет** сбора объявлений, обхода CAPTCHA/антибот-систем и автоматической рассылки.
- Модуль ответа на возражения пока представлен только базой сценариев и не доступен в интерфейсе.
- Перед отправкой готового сообщения менеджеру следует проверить его на соответствие исходному объявлению.

## Частые проблемы

**«Не настроен OpenAI API»** — убедитесь, что файл называется именно `.env`, ключ указан как `OPENAI_API_KEY=...`, затем перезапустите `run.bat`.

**«Не удалось получить ответ от AI»** — проверьте интернет, корректность ключа, доступность выбранной модели и наличие API-квоты.

**Порт 8000 занят** — закройте другое приложение на этом порту или запустите сервер вручную с другим портом, например `python -m uvicorn backend.main:app --port 8001`, и откройте `http://127.0.0.1:8001`.
